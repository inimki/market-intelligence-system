01

确定调研范围

行业填“储能”，公司填“宁德时代、阳光电源”，关注主题填“新品、产能、订单”。最多可填写 8 家公司。

02

提交并等待采集

点击“搜索并生成报告”。系统发现候选官网、采集公开内容并去重。网络或网站限制可能导致部分信源失败。

03

浏览、下载与核验

点击“在线浏览报告”或“下载 HTML”。沿报告中的原始链接核验重要信息。首次运行前暂无最新报告。

需要自动定时运行？

打开 n8n 管理页面，首次创建自己的管理账号。一键脚本会导入并发布“市场情报自动收集与报告”工作流，每天北京时间 08:00 执行。你的电脑和 Docker 必须保持运行。它会读取所有已启用信源。

AI 是可选项

普通网页采集和统计报告可以不填 Key。要启用 PandasAI 问答或 Browser Use 交互采集，请在本机 .env 中配置服务商、Key、接口地址和模型，再次双击一键部署。详细的 DeepSeek / OpenAI / 兼容服务示例在 TXT 说明第 6 节。

日常启动和排错

下载代码后，在已装好 Docker Desktop 的 Windows 上双击 一键部署.cmd。再次双击可更新并启动；停止服务执行 docker compose stop。网页出错时查看 docker compose logs --tail 80 nginx api。
