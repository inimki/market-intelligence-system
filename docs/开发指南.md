# 本地开发指南

完整平台使用根目录 `一键部署.cmd`。本页是 Python 开发路线，须安装 Python 3.11。
以下命令均在项目根目录 PowerShell 执行。不必激活环境，直接使用各环境的 Python。

## 基础 API 与离线演示

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m app demo --open
```

演示使用固定样例，不需要 Key；详见 [代码与数据流](一步一步理解系统.md)。
本地环境使用 `.env.example` 的 SQLite 配置；不要在 Docker 和本地开发服务间混用数据库。

## 独立采集和 AI 环境

Browser Use 与 PandasAI 的依赖存在冲突，需要独立环境：

```powershell
py -3.11 -m venv .venv-collector
.\.venv-collector\Scripts\python.exe -m pip install -e ".[collectors]"
.\.venv-collector\Scripts\python.exe -m playwright install chromium
py -3.11 -m venv .venv-ai
.\.venv-ai\Scripts\python.exe -m pip install -e ".[ai]"
```

创建 `.env` 后，在里面设置：

```dotenv
COLLECTOR_SERVICE_URL=http://127.0.0.1:8011
ANALYSIS_SERVICE_URL=http://127.0.0.1:8012
```

模型配置参见 [根目录使用说明](../使用说明.txt)。本地直接运行的进程需重启以读取配置；
Docker 中则执行 `docker compose up -d collector analysis` 更新环境。

分别打开三个 PowerShell 窗口：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

```powershell
.\.venv-collector\Scripts\python.exe -m uvicorn app.collector_service:app --host 127.0.0.1 --port 8011
```

```powershell
.\.venv-ai\Scripts\python.exe -m uvicorn app.ai_service:app --host 127.0.0.1 --port 8012
```

本地 API：http://127.0.0.1:8000/api/docs 。这条路线没有启动 Nginx 和 n8n；
Nginx 帮助页只在 Compose 部署下提供。不要与 Docker 同时占用 8000 端口。

## 主要代码入口

| 文件 | 作用 |
|---|---|
| `app/main.py` | 中文控制台和 API |
| `app/discovery.py` | 按行业与公司发现官网信源 |
| `app/pipeline.py` | 采集、标准化、去重和报告主流程 |
| `app/collectors/router.py` | 选择采集器 |
| `app/normalization.py` | URL 与文本规范化、内容指纹 |
| `app/analysis.py` | 确定性统计与可选 PandasAI 问答 |
| `app/reporting.py` | HTML 报告 |
| `deploy/nginx/default.conf` | 网页入口与反向代理 |
| `scripts/deploy.ps1` | 一键安装入口 |

## 验证

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check app tests
powershell -NoProfile -ExecutionPolicy Bypass -File tests/test-bootstrap.ps1
```

`tests/test-bootstrap.ps1` 在独立临时目录验证新配置创建、凭据随机性和重复运行保留配置。
它不读取项目真实 `.env`，也不会启动容器。
