## 范围和限制

干净副本验证覆盖学习站镜像构建和隔离 HTTP 服务，不等于重新执行了六个服务的
全量首次安装，也不代表外部采集网站或付费 AI 服务全部可用。
本轮没有替换现有业务容器、变更密钥或删除业务数据；原本机平台保持运行。
GitHub Actions 的最终结果以仓库 Actions 页面为准，不能用本机结果代替远端结果。

原学习站完整依赖树此前报告 13 个受影响包；本次公开静态发行版通过升级和去除
不需要的云端工具链，审计结果为 0。该结果不表示原独立 Sites 目录也已升级，
更不表示 Python、容器镜像及整个系统已完成全面漏洞审计。

Next.js 升级依据：[上游安全公告](https://github.com/vercel/next.js/security/advisories/GHSA-p293-qw3h-jr36)。
当前生产学习站是 Nginx 静态服务，不运行该公告描述的 Windows Next 服务端。
不要把依赖告警等同于已被入侵，也不要将“未检出”理解为绝对安全。
