参考日期：2026-09-06。本文记录设计来源，不表示使用了这些项目的源代码实现。

Nginx 将网页、API 和报告转发到 FastAPI，直接提供帮助页与 TXT。它不会代替应用逻辑，
也不会直接改善采集质量。它为以后增加域名、HTTPS、访问控制提供入口。
当前未自动申请证书、未发布公网域名，n8n 继续使用独立的本机管理端口。

## 初次运行和重跑

1. Docker 不可用时给出安装/启动指引，不静默修改 BIOS 或自动重启操作系统。
2. .env 不存在时以 CreateNew 创建，分别生成两份 32 字节随机十六进制凭据；
   十六进制不会引入数据库 URL 和 Compose 插值中的特殊字符。
3. 已存在的 .env 不覆盖，示例密码未修改时明确报错，避免改变已初始化数据库凭据。
4. Compose up --build 复用构建缓存并应用环境变化。
5. 添加信源仅限空数据库；工作流按稳定 ID 判断是否需要导入。
6. Nginx 配置与代理健康检查通过后才打开浏览器。

## 当前限制

- Windows 一键部署；Linux/macOS 保留手动 Compose 路线。
- 镜像构建仍需要网络，并非离线安装包，也没有发布预构建应用镜像。
- 默认监听 127.0.0.1；尚未提供完整多用户认证与公网部署方案。
- Nginx 900 秒只延长代理等待，不会把同步调研变为异步任务。
- AI 兼容服务需分别验证模型能力；本文未声明全部服务商均已测试成功。
- Python 依赖版本范围仍允许升级；首次安装可能与旧环境不同，需要持续测试。
