## 已解决的问题

1. Docker Desktop 首次显示“Virtualization support not detected”：重启后确认 WSL 2 与 Docker Engine 均正常。
2. Docker Hub 授权服务器超时：Python 基础镜像改用 AWS Public ECR 的 Docker Official Images 镜像。
3. PyPI 下载中断：容器构建改用阿里云 PyPI 镜像，并增加超时与重试。
4. n8n 空数据库导出返回非零：启动脚本允许“尚无工作流”并继续导入。
5. n8n 2.x 导入要求工作流 ID：工作流加入固定 ID `marketIntelDaily01`。
6. n8n 导入后未自动运行：启动脚本在首次导入后自动发布工作流。
7. Analysis 只读容器无法创建目录或日志：数据目录改到 `/tmp`，并关闭 PandasAI 文件日志。
8. Browser Use 首次下载扩展导致启动超时：关闭不需要的默认扩展和验证码求解功能。
